# Simple Webpage

This project is a simple webpage that demonstrates the basic structure of an HTML document, along with linked CSS for styling and JavaScript for interactivity.

## Project Structure

```
simple-webpage
├── src
│   ├── index.html       # Main HTML document
│   ├── styles
│   │   └── style.css    # Styles for the webpage
│   └── scripts
│       └── script.js     # JavaScript for interactivity
└── README.md            # Project documentation
```

## Getting Started

To set up and run the webpage, follow these steps:

1. **Clone the repository** (if applicable):
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd simple-webpage
   ```

3. **Open the `index.html` file** in your web browser:
   - You can simply double-click the `index.html` file or open it through your browser's file menu.

## Usage

- The webpage is styled using the `style.css` file located in the `src/styles` directory.
- Any interactive features are implemented in the `script.js` file located in the `src/scripts` directory.
